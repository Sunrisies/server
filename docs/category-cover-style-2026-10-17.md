# 分类默认封面样式

默认封面由 Rust 的 `src/services/category_cover.rs::render` 在请求时生成 SVG。无需人工预先生成图片，无外部绘图 API、图片下载、前端拼图或新增运行时依赖。

分类 ID 与名称计算稳定种子，选择四组配色和三种几何构图（轨道球体、分层几何块、环绕曲线）。背景增加网格、点纹、渐变光晕和分区排版；分类名最多 28 字符，长名称分行。保留 XML 转义、1200×630 尺寸、上传封面优先及无缓存旧内容的响应策略。

同一分类稳定展示同一封面。分类变化可改变配色/构图和名称；自定义封面仍复用已有七牛上传和引用保护流程。

检查：后端 66 项测试；三种实际 Rust 渲染样本浏览器检查；本地生产版接口检查 SVG 内容、匿名访问、文章列表加载、截图。仅更新本地，不部署线上。
