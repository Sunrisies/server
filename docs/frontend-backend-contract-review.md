# 前后端接口与鉴权修复（2026-10-15）

## 后端

- 原路径前缀放行所有方法，分类/标签/链接写操作没有有效认证门槛。现在公开读取与管理写入分开；管理操作校验数据库当前 ADMIN/SUPER_ADMIN 角色，撤销角色后旧 JWT 不能继续管理。频道登录和持有频道令牌的内容操作保持各自鉴权，创建频道要求管理员。精确匹配路径边界，保留文章浏览量计数。
- 游客只读取 status=1 的文章；草稿、下线内容不进入列表、详情、相邻文章或时间轴。管理员读取保留编辑需要的全部状态。
- 写入使用真实用户 UUID 对应的 ID；删除/编辑仍要求作者本人，权限不足返回 403。列表作者批量读取，详情作者实际读取。
- 分页验证 page>=1、1<=limit<=100，消除减一溢出及零大小分页；参数校验统一 422。Actix ResponseError 状态与业务错误码保持一致。
- 未绑定角色的用户登录返回错误，不能数组越界 panic。
- 增加 /posts/{uuid}/prevnext，保留原 /posts/prevNext/{uuid}。
- 文章详情的 content 仍为公开 Markdown；管理员额外获得 htmlcontent/markdowncontent，游客不返回这些额外编辑字段。

## 前端

- 仪表盘编辑入口改为有效的文章列表编辑链接，支持 UUID 深链接打开编辑弹窗。
- 编辑先加载完整文章详情，失败时不打开空表单；分别保存 HTML 与 Markdown，保留下线状态。连接旧后端缺少 htmlcontent 时，不把空 HTML 写回覆盖旧值。
- 标签页/时间轴支持后续分页加载、错误重试，隔离切换标签后的旧请求结果。
- 浏览量统计分页读取，取消 200 条请求及截断汇总。
- 剪贴板在实际 HTTP 401 时清除失效令牌，网络错误/503 保留令牌。
- 会话查询处理非 JSON、业务 401/403，保留正确失败状态。

## 验证与上线边界

后端使用独立 SQLite 内存库测试匿名写入、角色授予/撤销、草稿隔离、编辑数据及真实作者；前端有编辑/错误/分页专项测试与生产 SSR 集成测试。模拟环境不能替代生产 PostgreSQL、真实账号以及 Docker/Linux 回归。

尚需上线、轮换历史泄漏 JWT_SECRET、审计既有管理员；复制的有效 JWT 仍需后端撤销机制才能通过退出立即失效。房间、邮箱验证码、上传资源的限流及完整权限矩阵仍需专项审计。首屏 JS 和真实 CWV 仍有后续优化空间。
